# Scope

1. Student Exam Result Upload System

Faculty can upload student exam results in bulk using a predefined format (e.g., Excel or CSV).
The system will validate the uploaded file to ensure it meets the required format (e.g., student ID, exam ID, marks obtained).
Faculty can edit or update results if needed.


2. View Portal
The view portal will serve as a centralized platform for accessing exam-related information.
Students can:
View exam .
Access their exam results with detailed breakdowns (e.g., marks , for all subject that semester).
